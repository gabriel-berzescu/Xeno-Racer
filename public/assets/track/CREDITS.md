# Track assets — credits

All textures are CC0 (public domain), from [Poly Haven](https://polyhaven.com). Re-encoded to WebP
(1k, except `asphalt_track` and `leafy_grass` at 2k). Everything else in the track world (trees,
barriers, stands, buildings, signage, water normals, flags) is generated procedurally at runtime.

| Folder (`tex/<id>/`) | Poly Haven asset | Author(s) | Used for |
|---|---|---|---|
| `asphalt_track` | https://polyhaven.com/a/asphalt_track | Dimitrios Savva | racing surface |
| `leafy_grass` | https://polyhaven.com/a/leafy_grass | Charlotte Baglioni | grass / runoff |
| `rocky_terrain_02` | https://polyhaven.com/a/rocky_terrain_02 | Amal Kumar | lush mossy ground, variation |
| `forrest_ground_03` | https://polyhaven.com/a/forrest_ground_03 | Rob Tuytel | dirt / path / slopes |
| `gravel_floor` | https://polyhaven.com/a/gravel_floor | Jenelle van Heerden, Matterfield | gravel traps |
| `rock_face_03` | https://polyhaven.com/a/rock_face_03 | Dario Barresi, Rico Cilliers | cliffs, rock cuts |
| `concrete_wall_007` | https://polyhaven.com/a/concrete_wall_007 | Dario Barresi, Rico Cilliers, Charlotte Baglioni | barrier walls, buildings |
| `concrete_floor_worn_001` | https://polyhaven.com/a/concrete_floor_worn_001 | Dimitrios Savva, Rico Cilliers | concrete runoff / pit apron |
| `pine_bark` | https://polyhaven.com/a/pine_bark | Dimitrios Savva | tree trunks |

Each folder holds `diff.webp` (albedo), `nor.webp` (OpenGL normal map) and `rough.webp`.
